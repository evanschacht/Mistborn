# Project checkpoint workflow

- After every meaningful change, save the complete Roblox place, export updated project scripts, commit the complete project checkpoint, and push it to GitHub.
- Keep `Mistborn-Anchor-Prototype.rbxl` and `src/StarterPlayerScripts/` synchronized in each checkpoint.
- Verify the remote commit matches the local commit before reporting the checkpoint as backed up.
- Prefer Studio's direct Save command. Leave Play mode running after verification when practical.
- Do not export scripts injected by Roblox during Play mode as project source.
