# Coin pouch
Generated with the existing Three.js toolchain (revision 182); GLB inspected and materials consolidated in Blender 5.2.1.
The runtime uses the same primitive manifest through CoinPouchAsset, avoiding external asset IDs.
61 lightweight, massless, noncolliding parts per character: leather body, dark opening, rolled rim, belt loops, rivets, stitches and 15 independently hidden coins.
coin-pouch.blend is the Blender asset library. The source GLB and generator are included for future mesh import.
